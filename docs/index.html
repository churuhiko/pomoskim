Windows 11 desktop timer

PomodoroOverlay

作業の邪魔をせず、画面の隅で集中と休憩を支える軽量タイマー。

v0.3.0 preview

Windows版をダウンロード

Windows 11向けのプレビュー版です。GitHub Releaseから実行ファイルを取得できます。

EXEをダウンロード 全リリースを見る

GitHub Pagesで公開するとダウンロードリンクが有効になります。

シンプルな操作

Work 25m

25分の集中時間。完了すると休憩へ自動で切り替わります。

Break 5m

5分の小休憩。完了すると作業へ戻ります。

Windows通知

タイマー完了をWindows 11標準トーストで通知します。

実績記録

当日・当月・当年の完了数をローカルで集計します。

Googleカレンダー連携

前月の月報と前年の年報を終日予定として送信する、一方向の連携です。カレンダーの予定は読み取りません。
