起動と基本操作

GitHub Releaseから PomoSkin.exe をダウンロードして実行します。インストール作業は不要です。起動スプラッシュは表示せず、メイン画面を直接開きます。

操作内容
Work 25m25分の作業タイマーを選択します。
Break 5m5分の休憩タイマーを選択します。
Start選択中のタイマーを開始します。
Stop一時停止します。残り時間は保持されます。
Reset選択中のタイマーを初期時間へ戻します。
−ウィンドウを最小化します。設定によりタスクトレイへ収納できます。
×確認後にアプリを完全終了します。

作業が終わると休憩へ、休憩が終わると作業へ自動で切り替わります。完了時はWindows通知を表示し、実績へ記録します。

タスクトレイへ収納する

歯車ボタン → 一般 → 最小化時にタスクトレイへ収納する をオンにしてください。以降、最小化ボタンまたはタイトルバーの最小化で、タスクバーから隠れて通知領域へ収納されます。

  • 収納中もタイマー、通知、実績記録は継続します。
  • タスクトレイのPomo Skinアイコンをクリックまたは右クリックするとメニューを表示できます。
  • トレイアイコンのダブルクリック、左クリック、メニューの「表示」でウィンドウを復元できます。
  • 収納中にPomo Skinをもう一度起動すると、起動済みのウィンドウを前面に表示します。
  • トレイメニューの「完全終了」からタイマーを終了できます。

ポモドーロ終了時は、タスクバーに最小化している場合と同じ通知・切り替え動作になります。通知をクリックするとウィンドウを復元できます。

設定

  • 一般: 常に最前面、タスクトレイ収納、終了時の最新版確認を設定します。常に最前面は初期状態でオフです。
  • 通知: Windows通知と通知音を設定します。
  • 表示: 背景色、表示倍率、スキンを設定します。
  • 実績: 今日・今月・今年の完了数を確認し、月報・年報をカレンダーへ書き込みます。
  • 連携: Googleカレンダーとの一方向連携を設定します。
  • ヘルプ: 操作チュートリアルと開発者連絡先を確認できます。
設定変更は保存して閉じると反映されます。表示倍率や背景色は設定画面でプレビューされ、キャンセルすると元に戻ります。

最新版を確認する

一般設定の 終了時にGitHubで最新版を確認する をオンにすると、終了時にGitHub Releasesの最新版を確認します。最新版がある場合は公式ダウンロードページを開くダイアログを表示します。

公式ページから最新版を取得し、アプリを終了してからEXEを置き換えてください。自動上書きは行いません。通信できない場合は通常どおり終了します。

Googleカレンダー連携

連携を有効にすると、Pomo Skinは月報・年報をGoogleカレンダーへ新規の終日予定として書き込みます。既存予定の読み取り・検索・変更・削除は行いません。OAuth認証情報とトークンは利用者のPC内に保存されます。

困ったとき

  • 画面が見えない: タスクトレイのPomo Skinアイコンをクリックするか、PomoSkin.exeをもう一度起動してください。
  • 最前面にならない: 一般設定の「常に最前面に表示」を確認してください。初期状態はオフです。
  • 通知が出ない: Windowsの設定 → システム → 通知で、Pomo Skinの通知を許可してください。
  • 更新できない: GitHub Releaseの公開状態とインターネット接続を確認し、必要ならReleaseページから手動で新しいEXEをダウンロードしてください。

データとプライバシーもあわせて確認してください。
