# PomodoroOverlay v0.3 プレビュー

- 現在のプレビュー: `v0.3.0-preview.1`
- 対象環境: Windows 11
- 安定版ではなく、v0.3の機能追加と回帰確認を行うための開発ビルド

## プレビュー基盤

- バージョン番号は `version.py` で一元管理する。
- 設定画面、起動スプラッシュ、スプラッシュアセットキャッシュは同じバージョン番号を使用する。
- v0.2.999までの基本機能を維持する。

## ダウンロードページ

- トップページには最新版の `PomodoroOverlay.exe` と全リリースへのリンクを表示する。
- GitHub Pagesの標準URLでは、ページURLからGitHubの `OWNER/REPOSITORY` を自動判定する。
- カスタムドメインを使う場合は、`docs/index.html` の `data-github-repository` に `OWNER/REPOSITORY` を設定する。
- ダウンロード対象のRelease asset名は `PomodoroOverlay.exe` に固定する。

## 開発方針

v0.3の新機能は、既存の設定・実績・未送信レポートを壊さずに追加する。各機能は実装、回帰テスト、変更履歴を同じ作業単位で更新する。

## 確認コマンド

```powershell
python -m unittest discover -s tests -v
python -m PyInstaller --noconfirm PomodoroOverlay.spec
```
